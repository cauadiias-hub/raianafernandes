# Raiana Fernandes

Site institucional premium para Raiana Fernandes, com foco em psicoterapia para adolescentes, adultos e idosos.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```

Informações profissionais pendentes, como CRP, abordagem, formação, cidade completa, modalidade, valores e políticas de atendimento, devem ser adicionadas somente após confirmação.
